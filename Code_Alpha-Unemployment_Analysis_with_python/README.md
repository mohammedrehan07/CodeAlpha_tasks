# 📊 Unemployment Analysis in India using Python

This project analyzes unemployment rate data in India using Python.  
The goal is to clean, explore, and visualize unemployment trends and study the impact of COVID-19 on employment.

---

## 📁 Dataset

This project uses two CSV files:

- `Unemployment_in_India.csv`
- `Unemployment_Rate_upto_11_2020.csv`

### Dataset Features:
- Region (State)
- Date
- Estimated Unemployment Rate (%)
- Labour Participation Rate
- Area (Urban / Rural)

---

## 🎯 Objectives

- Clean and prepare unemployment data  
- Analyze unemployment trends over time  
- Study the impact of COVID-19 on unemployment  
- Identify state-wise unemployment patterns  
- Visualize insights using graphs  

---

## 🛠️ Tools & Libraries Used

- Python  
- Pandas  
- Matplotlib  
- Jupyter Notebook  

---

## 🧹 Data Cleaning Steps

- Removed extra spaces from column names  
- Standardized column names  
- Converted the Date column to datetime format  
- Merged both datasets  
- Removed invalid and missing values  

---

## 📈 Analysis Performed

### 1️⃣ Monthly Unemployment Trend
Visualized how unemployment rates changed over time.

### 2️⃣ COVID-19 Impact Analysis
Compared average unemployment rates before and after March 2020.

### 3️⃣ State-wise Unemployment Analysis
Identified states with the highest average unemployment rates.

---

## 📊 Key Findings

- Unemployment was relatively stable before 2020.  
- A sharp increase occurred after March 2020 due to COVID-19 lockdowns.  
- Significant variation exists between different states.  
- The data highlights how economic crises drastically impact employment.

---

## ▶️ How to Run

1. Open the Jupyter Notebook.
2. Place both CSV files in the same folder as the notebook.
3. Run the notebook cells one by one.

---

## 📌 Output

- Line graph showing unemployment trends  
- Bar chart of top 10 states by unemployment rate  
- Cleaned and merged CSV file  

---

## ✅ Conclusion

This project demonstrates how Python can be used for real-world data analysis.  
The insights highlight the economic impact of COVID-19 and the importance of effective employment policies during crisis situations.
