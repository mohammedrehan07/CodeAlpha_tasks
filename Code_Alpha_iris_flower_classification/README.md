# Iris Flower Classification — CodeAlpha Internship

This project is part of the CodeAlpha Data Science Internship Task.

In this project, a Machine Learning model is built to classify Iris flower species
(Setosa, Versicolor, Virginica) based on sepal and petal measurements.

## Technologies Used
- Python
- Pandas
- Seaborn
- Scikit-learn
- Matplotlib

## Model Used
Random Forest Classifier

## Result
The model achieved around 98% accuracy on test data.

This project demonstrates data preprocessing, exploratory data analysis,
classification, and model evaluation using machine learning.
